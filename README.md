# Scuola del Sabato — Registration form

Static registration form for the **Scuola del Sabato** (Saturday school) at
Italienska Skolan Stockholm. Hosted on GitHub Pages and embedded in
[italianskaskolan.se](https://www.italienskaskolan.se/).

| File | Purpose |
|------|---------|
| `scuola-del-sabato.html` | The registration form |
| `grazie.html` | Confirmation / Swish payment page |
| `logo-italienska-skolan.png` | School logo |

Italian only. No build step — open the HTML directly or serve statically.
